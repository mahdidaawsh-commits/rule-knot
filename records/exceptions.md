# Release policy (synthetic)
## signoff-exception
A release must include human sign-off unless it uses an expedited schedule. An expedited schedule waives this sign-off requirement but does not prohibit sign-off.
## recovery-exception
A release without human sign-off must support offline recovery. A release with human sign-off has no offline-recovery requirement under this clause.
## fast-no-recovery
If a release uses an expedited schedule, it must not support offline recovery.
